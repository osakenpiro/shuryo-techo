第一章 · 自分の部屋は4面

同じ部屋の中で、基本 → 机越し → 本棚越し・反射 → 風、と狙い方を変える。

1-1の結果から、はじめてのタイトルへ

チュートリアルと1-1を遊んだあと、結果を見てタイトルへ。遊びを先に味わってから、TRASHOOTの名前と世界が広がる。

スマホのタイトル画面も見る
一度タイトルが開いたあとは、メニューの「タイトルへ」でも戻れる。4面の途中で章トップへ戻ることもできる。お店へは、結果を閉じて次の面／再挑戦 → メニューから入る。

お店 · 同じ面を違う投げ心地で遊ぶ

メニュー下部 → お店 → 購入／持ち替え → 現在面をその物で再開始。

この42 → 2コインは撮影中の実プレイ例。自分の残高は、自分のクリアで貯めた分になる。クリアやベスト記録は持ち替えても消えない。

鉄球50コイン重く、跳ねにくい

物ごとのベストも保存。本編4面と、その面のトレーニングで持ち替えを使える。自由トレーニングや2Dの脇道は、今は空き缶。

入り方の実績と、一投の振り返り

「スコアの内訳」「この一投の分析」を開くと、実際に投げた角度や入り方を振り返れる。PCは右ドラッグで見回し、ホイール／「弧 −・＋」で弧を調整。スマホは「見回す」で視点操作へ切り替える。

メニューと、続きの保存・復元

遊ぶ・操作を調べる・記録を持ち出す。それぞれの入口を、3つの面へ。

保存コードと、一投の共有リンクは別。

続きを別のブラウザへ移すときは、TS2-で始まる保存コードを使う。一投の共有リンクは、成功ショットを見返すためのもの。リンクから進行やコインの復元はできない。

  1. 元のブラウザで「メニュー」→「記録」→「今の保存コードをコピー」。
  2. 移動先で「保存コードから復元する」に、控えたコードを貼る。
  3. 再開する面・クリア数・コイン・投げるものを確認し、「この記録に復元する」。
  4. 成功メッセージを確認し、続きから遊ぶ。

以前のTS1-も使用できる。TS1-は進行を復元し、今のコイン・装備は保持する。TS2-は進行・コイン・投げるものを復元する。復元すると、現在の進行をコードの内容へ切り替える。
