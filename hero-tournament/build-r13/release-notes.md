勇者トーナメント Windowsテスト版 r13

- 通常の打撃、防御、反撃で音と動きを変え、反撃が通った時の短い止めと押し返しを追加しました。
- 決着の強調は、同時に選んだ2手の結果が出そろってから表示します。
- 効果音のON/OFFと、動きを控える設定を追加しました。
- 戦闘の支払い・勝敗計算・保存形式と、r12のバッグ全体絵・回転表示は引き継いでいます。

ZIPをすべて展開し、以前の版を閉じてから `HeroTournament.exe` を起動してください。
初めてなら「妖精とチュートリアル」、すぐ遊ぶなら「ひとりでお試し」へ。

Windows向けテスト版です。必要な環境は従来と同じ .NET Framework 4.8 と Microsoft Edge WebView2 Runtime。
友だちとは同じ版で参加し、ホストのアプリを開いたままにしてください。回線の組み合わせによっては接続できない場合があります。

別PC・別回線での対戦と、人間同士の遊び心地は引き続き確認中です。
