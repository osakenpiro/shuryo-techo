勇者トーナメント Windowsテスト版 r14

- 報酬・成長で、3つの絵と名前・効果・増加量を同じ画面で比較しやすくしました。
- 対戦は案内を残しながら、5枚の手札の効果・魔力・耐久まで読めるように表示を整理しました。
- 戦闘中の通知を案内帯へ寄せ、手札や長いプレイヤー名への重なりを軽減しました。
- 戦闘ルール・支払い・保存形式・採用アート・カバンの全体絵と回転・効果音はr13から引き継いでいます。
- 既存r13の配布物と、独立レビューの固定原文・画像は保持しています。

ZIPをすべて展開し、以前の版を閉じてから `HeroTournament.exe` を起動してください。
初めてなら「妖精とチュートリアル」、すぐ遊ぶなら「ひとりでお試し」へ。

Windows向けテスト版です。必要環境は従来と同じ .NET Framework 4.8 と Microsoft Edge WebView2 Runtime。
友だちとは同じ版で参加し、ホストのアプリを開いたままにしてください。回線の組み合わせによっては接続できない場合があります。

別PC・別回線の対戦と、人間の理解・遊び心地の評価は引き続き確認中です。
