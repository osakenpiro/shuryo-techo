## RONDOの結論

単独実行者による利用者・編集・権利・技術・検査の観点比較。独立した複数エージェントの審査とは扱わない。

| 論点 | 比較 | 初版の決定 |
|---|---|---|
| 入口 | 動画一覧／経験別ゲート／用事別 | 用事別。経験は補助、一覧は奥 |
| 再生 | 初期から埋込／クリック後埋込／外部YouTube | 外部YouTube。ページ内再生を必須にしない |
| 要約 | 動画を視聴した体で生成／対応テキストから再構成 | 掲載元の対応テキストに限定。視聴済みと称さない |
| 数 | 多数を集める／各テーマ1〜3本 | 計9本。少数から実利用で改訂 |
| 時間 | YouTube未取得値を推定／掲載元の概算 | 「約」を付けた掲載元の値。5分フィルタも概算 |
| 点数 | 概算を精算に流用／学習と計算を分離 | 概要と精算を明示分離、#402へ |
| 保存 | アカウント・同期DB／端末内 | localStorageのみ。保存不可時はメモリ内と警告 |
| スマホ | 動画の小型埋込／大きい操作＋アプリへ | 18px基準、22px切替、主要ボタン48px以上 |
| タブレット | スマホの単純引伸し／横幅を利用 | テーマ3列・動画2列（700px以上） |
| helper未公開 | 404へ遷移／公開まで学習も停止／退避 | 同一オリジンで接続確認、失敗時は準備中＋再試行 |

自動再生・YouTube API・外部フォント・サムネイル・広告計測・第三者スクリプトなし。初期のfetchは同一オリジンのhelperだけ。YouTubeはユーザー操作で別タブ／アプリへ。外部遷移後は移動先のポリシーを適用。

## 選定基準

必須: 正規掲載元が追える、内容根拠が読める、対象テーマが一致する、誤解を補足できる、無断転載や煽りに依存しない。

優先: 短い、一つの学びに集中、初心者の用語負担が少ない、動画がなくても文章で学べる。

実動画の字の大きさ・発話の速さ・音の明瞭さ・今の再生可否は、今回の取得環境では判定していない。これらを確認済みとして選定スコアに加点しない。初版は**文章根拠による仮選定**であり、9本全編の視聴検収を完了した状態ではない。

初版をSignalTalk「麻雀のすべて」／土田浩翔氏の解説シリーズに寄せた理由は、動画と対応する解説本文が公開され、要約の根拠を追えるため。他の全チャンネルと比較したランキングではない。

## テストと制約

Chromiumの`set_content`によるDOM／レイアウト／操作検査: **66項目PASS**。

- 6テーマhash、全9本、概算5分以内5本、長い動画の除外、空結果からの回復。
- ブックマークのJSON読み戻し、削除後のキーボードフォーカス、壊れたJSON、不正ID、保存拒否時の警告。
- コピー不可時の手動コピー欄とフォーカス復帰。
- 320/390/768/1024px × home/all/call × 18/22/36px文字で横スクロールなし（36条件）。36pxは基準18pxの200%相当の文字サイズ検査であり、ブラウザのズーム挙動全般を保証しない。
- helperの公開／未公開分岐、JavaScript無効時の6掲載元リンク、iframe・画像なし、未捕捉JS例外なし。

**重要な検査境界**: この実行環境ではChromiumのHTTP／fileナビゲーションが管理ポリシーで拒否された。そのため保存の再読込とhelper応答は明示的なモック。実オリジンでのlocalStorage永続性、実iPhone/iPadの操作、YouTubeの再生成功をこの66項目に含めていない。表示スクリーンショットは実HTMLのDOMレンダリングであり、完成イメージの生成画像ではない。

実機の受入観測: お義父さんが入口を迷わず選べるか → 牌や声を認識できるか → YouTubeから学習ページへ戻れるか → LINE内ブラウザとSafariで保存場所が違うことを理解できるか。結果により初号動画・文字量・再生方式を更新。
