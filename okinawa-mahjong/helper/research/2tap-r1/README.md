# 2TAP UX RONDO — 麻雀ヘルパー R1

2タップは操作数の上限ではない。既存の紙・緑・牌の意匠と配布表の既定表示を維持し、用事への寄り道だけを変更。

## BEFORE → AFTER
| 対象 | BEFORE | AFTER |
|---|---|---|
| 符補助から点数計算へ | 反映 → 配布表 → 詳細計算（ボタン2回） | 反映 → 詳細計算（ボタン1回） |
| 役を見る：最初の役の位置 | 390px幅で上端594.56px | 463.52px（約131px上へ） |
| よく聞くことば | 全バッジを先に表示 | 同じ画面内で必要時に開く |
| 普通に点数ページへ入る | 配布表 | 配布表のまま |

375×812 / 390×844 / 414×896 のEdge Chromiumモバイルエミュレーションで横あふれ・pageerrorなし。実スマホのSafariや人の対局中の実利用は未検証。

## 開く → 用事を果たす
子ロン・2翻25符の条件指定：点数 → 詳細 → 2翻 → 25符 → 役あり確認 → 支払点を見る（6ボタン、初期の子/ロンが実際と一致する場合）。1,600点を表示し、役あり未確認時は拒否。これは2タップに丸めない。役の鳴き可否：役を見る → カードの表示を読む。名前検索・用語展開も検証。符補助の七対子25符は引き継ぐが、翻・役ありを勝手に確定しない。

## 操作分類
| 操作 | 分類 | 扱い |
|---|---|---|
| 実際の親子・あがり方・翻・役の有無 | REQUIRED | 不明な事実を推測で埋めない |
| 符補助の計算値と反映先 | DERIVABLE | 値と詳細モードを一緒に引き継ぐ |
| 本場・供託0、通常入口の配布表 | DEFAULTABLE | 既定を維持し変更可能にする |
| 用語バッジ・注記 | DEFERRABLE | 同じ画面内の折りたたみへ |
| 符を反映した後の詳細モード再選択 | REMOVE | 行き先の意図は直前の操作で確定済み |
